Record Log Entry

The Record Log Entry page enables you to record information relating to work done for associated objects.

Record Log Entry Page Field Definitions

This table defines the fields on the Record Log Entry page.

Field

Definition

Operator Log

Select a predefined log for the entry.

Required

Log Entry Type

List of available log entry types. Available types are defined by the group set for the selected operator log.

Required

Displays the object type associated with the selected Operator Log and Log Entry Type.

Display Only

Log Entry

Enter text for the log entry. For example, for a Resource object type, an entry of resource maintenance information.

The field accepts a maximum of 255 characters. The application truncates the data if the comments exceed 255 characters.

Optional

Log Entry Type Filter

List of log entry types to use to filter the entries in the Record Log Entry Detail grid.

Optional

Start Date

Beginning date of the date range within which the transactions occurred. Results include only log entries occurring after this date. The application defaults the start date to yesterday's date and a time of 12:00 AM when you select the Select date range option. You can enter a different date and time using the mm/dd/yyyy hh:mm AM/PM format or select the date and time by clicking the calendar icon to use the date picker control.

Optional

End Date

Last date of the date range within which the transactions occurred. Results include only log entries occurring before this date. The application defaults the end date to today's date and the current time when you select the Select date range option. You can enter a different date and time using the mm/dd/yyyy hh:mm AM/PM format or select the date and time by clicking the calendar icon to use the date picker control.

Optional

Log Entry Filter

Enter data to search for in the content of saved log entries. You must tab out of the field or press enter to apply the entered data to the grid filter.

Optional

How to Record a Log Entry

Follow these steps to record a log entry:

1. Open the Record Log Entry page. The Record Log Entry page appears.
2. Select an Operator Log.
3. Select a Log Entry Type.
4. Complete the Log Entry field with the entry information.
5. Enter optional information according to your business requirements. Refer to the field definitions table for information on the optional fields.
6. Click Record Log Entry. The application displays a status message confirming the entry has been recorded.
