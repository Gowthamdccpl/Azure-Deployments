SPC 测试器

Siemens 提供了 SPC 测试器，用于测试应用程序中包含的样本图表和数据。还可以在配置了图表和必需组件后测试安装程序。

Siemens 提供了可以通过 Management Studio 加载的样本图表和数据。

使用 SPC 测试器页

必须选择“容器”、“SPC 图表”、“SPC 图表组”或“数据收集”。所有其他字段都是可选字段。

如果选择容器，会自动过滤“SPC 图表”、“SPC 图表组”和“数据收集”字段。选择容器后，这些字段仅会显示与所选容器关联的值。

可以在运行时将参数传递给图表，以添加新参数或修改和移除“用户参数”表格上的现有参数。在此页面上输入的 UI 参数将替代 SPC 图表对象中设置的参数。有关为 SPC 图表定义参数的信息，请参考“定义 SPC 图表”。

注释: “SPC 测试器”页上不能使用动态值。

测试数据可通过 Management Studio 中的 DB 更新加载。Siemens 建议只在开发环境中而不要在生产环境中加载该数据。

样本宏和样本图表指向从 DB 更新加载的数据。样本图表中的路径指向默认安装位置。如果没有使用默认安装位置，则需要更新路径。

在使用测试器页之前，还必须更新具有 ODBC 身份验证信息的样本宏。

在此页上输入的 UI 参数将替代在“SPC 图表”对象中设置的参数。

如何使用 SPC 测试器页

按照以下步骤使用“SPC 测试器”页：

1. 从 SPC 菜单中选择SPC 测试器。将显示“SPC 测试器”页。
2. 选择容器、SPC 图表、SPC 图表组或数据收集。
注释: 只有一个字段为必填字段。
3. 选择一个或多个可选字段，以进一步定义要生成的图表。
4. 单击提交。将显示所选图表。
5. 是否要下载图表或图表组？

如果 ...

操作步骤 ...

是
a. 单击下载图像。应用程序会提示打开或保存该文件，或者它会自动下载该文件。（Internet 浏览器将确定应用程序是否显示弹出窗口、应用程序的外观以及“打开”或“保存”选项的措辞。）

注：如果无权在设备上下载文件，浏览器将显示一条错误消息。

b. 选择要执行的作业，并完成任何使用特定应用程序打开文件的步骤或将文件保存到计算机的其他步骤。
c. 单击右上角的 X 关闭图表弹出窗口。

否

单击右上角的 X 关闭图表弹出窗口。

如何保存 SPC 日志文件

按照以下步骤保存图表日志以进行故障排除：

注释: 保存 SPC 日志文件之前，必须在 SPCLogPath 集成接口设置中定义文件路径。有关信息，请参考《Opcenter Execution Medical Device and Diagnostics Portal 2.0 用户指南》或《Opcenter Execution Core Portal Studio 用户指南》。
1. 从 SPC 菜单中选择 SPC 测试器。将显示“SPC 测试器”页。
2. 选择容器、SPC 图表、SPC 图表组或数据收集。
注释: 只有一个字段为必填字段。
3. 选中“保存 SPC 日志”复选框。
4. 选择一个或多个可选字段，以进一步定义要生成的图表。
5. 单击提交。将显示所选图表。日志文件保存到 SPCLogPath Portal 设置中指定的文件路径。导览至该位置以查看保存的日志。
