inner CalculateVariableStatistics(param) → {CalculateVariableStatisticsResponse}

This endpoint calculates the input data and returns the response object. Depending on specification and configuration it calculates the subgroups, statistic values, and process violations.

Parameters:
Name Type Description
param CalculateVariableStatisticsRequest

Parameter for CalulateVariableStatistics method. It summarizes all measurement data, optional historical data and configuration/specification data of a control chart for a variable characteristic. The content is used for input of CalulateVariableStatistics.

Response Parameter of CalculateVariableStatistics method. It summarizes all measurement data, calculated data and optional historical data as well as configuration/specification data of a control chart for variable characteristic. Also, the configuration/specification data can be enhanced or modified to default values.

CalculateVariableStatisticsResponse
