Virtual Directories for documentation

This step is an optional step it is only necessary if you want to attach the End User Documentation, the Installation Manual and the Chart Library Documentation to the API Index Page.

[fig.1] Links to different Documentation files in API Index Page

- Adding Documentation virtual directory

  • Right click on the API web Site in IIS
  • Click on Add Virtual Directory...
  • in the Alias Filed please type Documentation, this Folder should reference the Documentation Folder in the installation package this folder is located in <INSTALLATION_PACKAGE_PATH>\dist\Documentation
