static onSeriesClick(data)

The series click callback event.

Parameters:
Name Type Description
data object

The object hold the information of clicked point.
sequenceId number

The corresponding sequence id of the clicked point.
seriesName string

The clicked series name.
point number

The clicked point value
seriesId string

The id of the clicked series.
Example
// When a callback is registered with options in single value chart options
 $('#svc').singleValueChart(
                 {
                     locale: "en",
                     data: {
                         specification: {
                                  controlChartType : 'xb'
                              },
                         measurements : [], // Array of objects in defined format
                         subgroups: [],  // Array of objects in defined format
                     },
                     decimalPlaces: 2,
                     hiddenSeries: ["lcl"],
                     onSeriesClick: function (data) {
                                         console.log(data);
                                         //The output will be like this
                                         // sequenceId: 484, seriesName: "measurements__1", point: 19.99, seriesId: "measurements__1"
                                         }
                  }
               );

Type Definitions

object

customInfo

An array of objects with following properties can be injected against each measurements.

Properties:
Name Type Description
label string

The label to be display in tool tip .
value string

The value to be used to show in tool tip and for xAxis labels.
showInTooltip boolean

if true, the label and value will also be shown in tool tip for a particular subgroup as 'label: value'
xAxisLabel boolean

If true then value of will be shown on xAxis labels instead of default labels. e.g. subgroup number
isRemark boolean

If this flag is set then the value will be shown when in measurement (input object to charts) contains statuses property with category Remark
Example

A customInfo can be injected like this, if a data is defined in the given MultiVarSingleValueChart.data.variableResponse

    data.variableResponse[0].measurements[0].customInfo = [
        {
            label: 'Charge Number',
            value: 'CH001',
            showInTooltip: true,
            xAxisLabel: false
        },
        {
            label: 'Date',
            value: '05-01-2020',
            showInTooltip: true,
            xAxisLabel: true,
            isRemark: true
        }
    ];

object

legendSettings

the values to set the legend to the preferred position or to hide it totally

Properties:
Name Type Attributes Default Description
enabled boolean <optional>
 true

show or hide the legend.
align string <optional>
 right

The horizontal alignment of the legend box within the chart area. Valid values are left, center and right.
verticalAlign string <optional>
 top

The vertical alignment of the legend box. Can be one of top, middle or bottom.
layout string <optional>
 vertical

The layout of the legend items. Can be one of horizontal or vertical or proximate. When proximate, the legend items will be placed as close as possible to the graphs they're representing, except in inverted charts or when the legend position doesn't allow it.
x number <optional>
 0

The x offset of the legend relative to its horizontal alignment align within chart.spacingLeft and chart.spacingRight. Negative x moves it to the left, positive x moves it to the right.
Y number <optional>
 0

The vertical offset of the legend relative to it's vertical alignment verticalAlign within chart.spacingTop and chart.spacingBottom. Negative y moves it up, positive y moves it down.
object

options

object with all neccesarry information for the chart

Properties:
Name Type Attributes Default Description
data MultiVarSingleValueChart.data

Array of variables up to n Variables each variable contains subgroups measurements and all other info
options.locale string <optional>
 en

User locale
options.chartTitle string

The chart's main title.
options.decimalPlaces number <optional>
 4

The number of digits to appear after the decimal point.
options.height number <optional>
 null

The chart height in pixel unit or as percentage %. An explicit height for the chart. If a number, the height is given in pixels. If given a percentage string (for example '56%'), the height is given as the percentage of the actual chart width. This allows for preserving the aspect ratio across responsive sizes.
By default (when null) the height is calculated from the offset height of the containing element, or 400 pixels if the containing element's height is 0.
options.width number <optional>
 null

The chart width in pixel. This is an explicit width for the chart. By default (when null) the width is calculated from the offset width of the containing element.
options.xAxisTitle string <optional>
 null

The x-Axis label displayed underneath the x-axis.

 false

Enable or disable the initial animation

if all variables in the variableResponse - object has the same specifications must set to true, otherwise it must be false
