CumulativeCountChart

Provide methods to draw cumulative count chart .

Methods

static createBase64Image(options)

  • Export the chart as base 64 image. Only support the compatible HTML5 browsers. For IE, it requires canvg.js from v3.0.8 to onwards.
Parameters:
Name Type Attributes Description
options object

An object with specified properties
containerId string

The id of an html input element e.g. base64Image when a tag is defined like this

width number <optional>

The width of chart. By default will take the chart container width where chart is rendered.
height number <optional>

The height of chart. By default will take the chart container height where chart is rendered.
success function

Callback when chart is rendered.
error function <optional>

Callback to get error information.
  • module:exporting.js
  • module:offline-exporting.js
  • module:canvg.js
Example
$('#cumulativeCountChart').cumulativeCountChart('createBase64Image',
                                      {
                                          containerId : 'sImageBase64',
                                          width : 1800,
                                          height: 600,
                                          success: function(){
                                                              console.log(document.getElementById('sImageBase64').value);
                                          },
                                          error: function(e) {
                                                              console.log(e);
                                          }
                                      });

static cumulativeCountChart(options)

Draw cumulative count chart with the given parameters.

Parameters:
Name Type Description
options CumulativeCountChart.options

The chart options parameter
  • module:highstock.js
  • module:jQuery.js
Example
$('#CUSum').cumulativeCountChart({
                     locale: locale,
                     data: {
                             subgroups: [
                                           {
                                           subgroupNumber: 1,
                                           cumulativeCount: 1,
                                           lowerControlLimitAbs: 39.98666666666667,
                                           upperControlLimitAbs: 2395.7869569035784,
                                           numberOfDefects: 4,
                                           processMeanValue: 559.8133333333333,
                                           statuses: 
                                              [ 
                                                 {
                                                     category: "LCL_1"
                                                 },
                                                 {
                                                     category: "ProcessViolation_1"
                                                 }
                                              ]
                                           }
                                        ]
                              },
                     decimalPlaces: 4,
                     height: '80%',
                     width: 400,
                     });

Type Definitions

object

customInfo

An array of objects with following properties can be injected against each subgroup.

Properties:
Name Type Description
label string

The label to be display in tooltip.
value string

The value to be used to show in tooltip and for xAxis labels.
showInTooltip boolean

if true, the label and value will also be showin in tooltip for a particular subgrup as 'label: value'
Example

A customInfo can be injected like this, if a data is defined in the given CumulativeCountChart.data

    data.subgroups[0].customInfo = [
        {
            label: 'Charge Number',
            value: 'CH001',
            showInTooltip: true,
            xAxisLabel: false
        },
        {
            label: 'Date',
            value: '05-01-2020',
            showInTooltip: true,
            xAxisLabel: true
        }
    ];
  // Note: If against a subgroup more than one objects have 'xAxisLabel' true then the value by default
  // of the first object will be taken. e.g. If in the given example both objects have xAxisLabel true
  // then in chart the value of first object on xAxis label (for subgroup 0) will be displayed.
  // Which is in this case 'CH001'

object

legendSettings

the legend position settings

Properties:
Name Type Attributes Default Description
legendSettings.enabled boolean <optional>
 true

show or hide the legend.
legendSettings.align string <optional>
 right

The horizontal alignment of the legend box within the chart area. Valid values are left, center and right.
legendSettings.verticalAlign string <optional>
 top

The vertical alignment of the legend box. Can be one of top, middle or bottom.
legendSettings.layout string <optional>
 vertical

The layout of the legend items. Can be one of horizontal or vertical or proximate. When proximate, the legend items will be placed as close as possible to the graphs they're representing, except in inverted charts or when the legend position doesn't allow it.
legendSettings.x number <optional>
 0

The x offset of the legend relative to its horizontal alignment align within chart.spacingLeft and chart.spacingRight. Negative x moves it to the left, positive x moves it to the right.
legendSettings.Y number <optional>
 0

The vertical offset of the legend relative to it's vertical alignment verticalAlign within chart.spacingTop and chart.spacingBottom. Negative y moves it up, positive y moves it down.
object

navigator

The navigator object is to define start and end of navigator range as well as the number of selected values

Properties:
Name Type Attributes Default Description
start number <optional>

first value to be selected in the navigator when defined alone then the last n values would be selected.
end number <optional>

last value to be selected in the navigator when defined alone then the first n values would be selected
selected number <optional>
 25

the number of selected value in the navigator, if start and end are set this value has no effect.
Example
navigator: {
              start: 0,
             end: 5,
              selected: 5
          },
object

options

Properties:
Name Type Attributes Default Description
options.locale string <optional>
 en

User locale for tooltip and title etc. It require corresponding localization files to be referenced in html e.g. ui-charts-de.js should be included for german locale.
options.data CumulativeCountChart.data

JSON Array with subgroup
legendSettings CumulativeCountChart.legendSettings

Settings for position, layout and visibility of the chart legend
options.chartTitle string <optional>
 'Cumulative Count Chart'

The default value will be based on corresponding locale (if referenced).
options.decimalPlaces number <optional>
 4

Number of decimal places for numbers to be shown in tooltip.
options.height number <optional>
 null

The chart height in pixel unit or as percentage %. An explicit height for the chart. If a number, the height is given in pixels. If given a percentage string (for example '56%'), the height is given as the percentage of the actual chart width. This allows for preserving the aspect ratio across responsive sizes.
By default (when null) the height is calculated from the offset height of the containing element, or 400 pixels if the containing element's height is 0.
options.width number <optional>
 null

The chart width in pixel. This is an explicit width for the chart. By default (when null) the width is calculated from the offset width of the containing element.
options.xAxisTitle string <optional>
 'subgroups'

The label for x-Axis.
options.yAxisTitle string <optional>
 'Cumulative Count'

The label for y-Axis.
options.xAxisCustomInfoLabel boolean <optional>
 false

If true, the default label for xAxis will be overriden by the property of customInfo object, where xAxisLabel is true. For more information please refer CumulativeCountChart.customInfo
animation boolean <optional>
 false

Enable or disable the initial animation
options.navigator CumulativeCountChart.navigator <optional>

The navigator object is to define start and end of navigator range as well as the number of selected values
fontSize CumulativeCountChart.fontSize <optional>

Option to set Fontsize of label & title.
