SingleValueChart

Provide methods for single value chart .

Methods

static addMeasurement(newMeasurement)

To add a new point in measurment series.

Parameters:
Name Type Description
newMeasurement object | number

If The value of the point that need to added. Only measurement series will be updated.
The corresponding limit will be increase based on their last values.
If the limits need to be update manually then an object should be passed as mentioned in the example below
Example
//To add just a new point in single value chart
$('#SVC').singleValueChart('addMeasurement', 20.09);
// To just add a new measurement value. The limits e.g. control limit etc. will be taken from previous measurement.

// To add new measurement values with limits
$('#SVC').singleValueChart('addMeasurement', {
    measurement: 20.14,  // new measurment value
    lcl: 10.03,  // lower control limit
    ucl: 20.09,  // upper control limit
    lwl: 10.02,  // lower warn limit
    uwl: 20.05,  // upper warn limit
    ltl: 19.65,  // lower tolerance limit
    utl: 19.95,  // upper tolerance limit
    xbp: 20.001, // process mean value
    nominalValue: 20.011, // nominalValue (if different from subgroup)
    averageOfAllValues: 20.125,  //average of all mesured valus
    additionalMeasurement: 20.77,  //for additional mesurements, if needed
    customInfo: [
                  {
                      label: 'custon Info',
                      value: 'added by function',
                      showInTooltip: true,
                      xAxisLabel: false
                  },
                  {
                      label: '2. custo Info',
                      value: 'info for tooltip',
                      showInTooltip: true,
                      xAxisLabel: true,
                      isRemark: true
                  }
              ]
  });

static addRemarks(sequenceId, remarks)

This method add/update the remark string for statuses Remark in measurement object. Usually Remark object is shown as green diamond shape.

Parameters:
Name Type Description
sequenceId number

The sequence Id of the point where a remark should be added.
remarks string

The new remark text.
Example
$('#SVC').singleValueChart('addRemarks', 397, 'new remark')
// If there is already a remark through customInfo passed, it will be updated. In other case new remark will be added for corresponding sequence id.

static createBase64Image(options)

  • Export the chart as base 64 image. Only support the compatible HTML5 browsers. For IE, it requires canvg.js from v3.0.8 to onwards.
Parameters:
Name Type Attributes Description
options object

An object with specified properties
containerId string

The id of an html input element e.g. base64Image when a tag is defined like this

width number <optional>

The width of chart. By default will take the chart container width where chart is rendered.
height number <optional>

The height of chart. By default will take the chart container height where chart is rendered.
success function

Callback when chart is rendered.
error function <optional>

Callback to get error information.
  • module:exporting.js
  • module:offline-exporting.js
  • module:canvg.js
Example
$('#singleValueChart').singleValueChart('createBase64Image',
                                      {
                                          containerId : 'sImageBase64',
                                          width : 1800,
                                          height: 600,
                                          success: function(){
                                                              console.log(document.getElementById('sImageBase64').value);
                                          },
                                          error: function(e) {
                                                              console.log(e);
                                          }
                                      });

static filterSVC(filters)

  • measurements may be filtered by the values of a specific customInfo. There can be a Choice of values, separated by colon.
Parameters:
Name Type Description
filters array

an Array of objects [ { label: 'Charge Number', value: 'CH00479;CH00480;CH00481;CH00482;CH00483;CH00484' }]
Example
$('#SVC').singleValueChart('filterSVC', [ { label: 'Charge Number', value: 'CH00479;CH00480;CH00481;CH00482;CH00483;CH00484' }]
                                        [ { label: 'Color', value: 'red;blue' }] );
This filter looks in every measurement for 
      custom info called 'Charge Number' with one of the values in 'CH00479;CH00480;CH00481;CH00482;CH00483;CH00484'
      OR
      custom info called 'Color' with one of the values in 'red;blue'
      
Only the measurement with matching filters are displayed

static updatePoint(sequenceId, newValue)

This method update the value of a measurement series point. The point can be updated based on provided sequence Id.

Parameters:
Name Type Description
sequenceId number

The sequence Id of the point that need to be updated.
newValue number

The new Value of the Point that need to be updated.
Example
$('#SVC').singleValueChart('updatePoint', 500, 20.09);
// This will update the 500th measurment value with 20.09, if 500th measurement is available.
// Otherwise no update will be done. On console the corresponding error can be then seen.

customInfo

An array of objects with following properties can be injected against each measurements.

Properties:
Name Type Description
label string

The label to be display in tool tip .
value string

The value to be used to show in tool tip and for xAxis labels.
showInTooltip boolean

if true, the label and value will also be shown in tool tip for a particular subgroup as 'label: value'
xAxisLabel boolean

If true then value of will be shown on xAxis labels instead of default labels. e.g. subgroup number
isRemark boolean

If this flag is set then the value will be shown when in measurement (input object to charts) contains statuses property with category Remark
Example

A customInfo can be injected like this, if a data is defined in the given SingleValueChart.data

	data.measurements[0].customInfo = [
		{
			label: 'Charge Number',
			value: 'CH001',
			showInTooltip: true,
			xAxisLabel: false
		},
		{
			label: 'Date',
			value: '05-01-2020',
			showInTooltip: true,
			xAxisLabel: true,
			isRemark: true
		}
	];
  // Note: If against a subgroup more than one objects have 'xAxisLabel' true then the value by default
  // of the first object will be taken. e.g. If in the given example both objects have xAxisLabel true
  // then in chart the value of first object on xAxis label (for subgroup 0) will be displayed.
  // Which is in this case 'CH001'

yAxisScale

The yAxisScale object is to determine the min/max value of the yAxis if the user provide values for Min and Max then MinScaling and MaxScaling does not affect the scaling either the user specifies numeric values for min and mix or specifies the scaling behavior according to scaling

Properties:
Name Type Attributes Default Description
min number <optional>

The minimum value of the axis. If null or undefined the minimum value is calculated based on scaling.
max number <optional>

The maximum value of the axis. If null or undefined the maximum value is calculated based on scaling.
minScaling scaling <optional>
 scaling.default

The vertical alignment of the legend box. Can be one of top, middle or bottom.
maxScaling scaling <optional>
 scaling.default

The layout of the legend items. Can be one of horizontal or vertical or proximate. When proximate, the legend items will be placed as close as possible to the graphs they're representing, except in inverted charts or when the legend position doesn't allow it.
