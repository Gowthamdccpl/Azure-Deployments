ProbabilityPlot

Provide methods for drawing Probability Plot.

Methods

static changeToleranceLinesVisibility()

Toggles between visible and unvisible tolerance lines

Example
//to change visibility of the tolerance lines
 $('#pnet').probabilityPlot('changeToleranceLinesVisibility');
 // this changes the tolerance lines from visible to unvisible or from unvisible to visible depending on the current state.

static createBase64Image(options)

  • Export the chart as base 64 image. Only support the compatible HTML5 browsers. For IE, it requires canvg.js from v3.0.8 to onwards.
Parameters:
Name Type Attributes Description
options object

An object with specified properties
containerId string

The id of an html input element e.g. base64Image when a tag is defined like this

width number <optional>

The width of chart. By default will take the chart container width where chart is rendered.
height number <optional>

The height of chart. By default will take the chart container height where chart is rendered.
success function

Callback when chart is rendered.
error function <optional>

Callback to get error information.
  • module:exporting.js
  • module:offline-exporting.js
  • module:canvg.js
Example
$('#probabilityPlot').probabilityPlot('createBase64Image',
                                      {
                                          containerId : 'sImageBase64',
                                          width : 1800,
                                          height: 600,
                                          success: function(){
                                                              console.log(document.getElementById('sImageBase64').value);
                                          },
                                          error: function(e) {
                                                              console.log(e);
                                          }
                                      });

static probabilityPlot(options)

A new Probability Plot can be drawn using this method.

Parameters:
Name Type Description
options ProbabilityPlot.options

The chart options parameter
Tutorials:
  • Probability Plot
  • module:highstock.js
  • module:jQuery.js
Example
$('#pnet').probabilityPlot({
                 locale: 'en',
                 data: data,
                 decimalPlaces: 4,
                 height: 600,
                 width: undefined
                 });

onChartLoaded(e)

The callback which is called when a probability plot is drawing.

Parameters:
Name Type Description
e object

The event object with chart API object
Example
$('#pnet').probabilityPlot({
                          locale: 'en',
                          data: data,
                          decimalPlaces: 4,
                          height: 600,
                          width: undefined,
                          onChartLoaded : function (data) {
                                         console.log(data);
                          }
                 });
Object

options

Properties:
Name Type Attributes Default Description
locale string <optional>
 en

User locale to display label and violations in a specific language
data ProbabilityPlot.data

JSON Array with subgroup
decimalPlaces number <optional>
 4

Number of decimal places
height number <optional>
 null

The chart height in pixel unit or as percentage %. An explicit height for the chart. If a number, the height is given in pixels. If given a percentage string (for example '56%'), the height is given as the percentage of the actual chart width. This allows for preserving the aspect ratio across responsive sizes.
By default (when null) the height is calculated from the offset height of the containing element, or 400 pixels if the containing element's height is 0.
width number <optional>
 null

The chart width in pixel. This is an explicit width for the chart. By default (when null) the width is calculated from the offset width of the containing element.
yAxisUnit ProbabilityPlot.yAxisUnit <optional>

The unit of y Axis if the parameter is not provided the title would be loaded from the corresponding localization.
xAxisTitle string <optional>

The label for x-Axis if the parameter is not provided the title would be loaded from the corresponding localization.

The label for y-Axis.
chartTitle string

The title of the chart if no value provided the corresponding localization value would be displayed

the Chart Title if the parameter is not provided the title would be loaded from the corresponding localization.

Enable or disable the initial animation

object

titleSettings

The titleSettings object is to determine the position and rotation of the chart title

Properties:
Name Type Attributes Default Description
align string <optional>

The horizontal alignment of the title. Can be one of "left", "center" and "right".
rotate number <optional>

The rotation of the text in degrees. 0 is horizontal, 270 is vertical reading from bottom to top.
x number <optional>
 undefind

The x position of the title relative to the alignment
y number <optional>
 undefind

The y position of the title relative to the alignment
Example
titleSettings:{
 align: 'left',
 rotate: '90',
 x: '35',
 y:'207'
},
object

yAxisUnit

To specify the series yAxis unit related properties.

Properties:
Name Type Attributes Default Description
text string <optional>
 ""

To specify the series colors.
x number <optional>
 60

x position of the text.
y number <optional>
 -6

y position of the text.
fontSize number | string <optional>
 null

The font size of the text. If as number will be given then unit will be in pixel. As string in points can be size given e.g. '12pt'
Example
$('#pnet').probabilityPlot({
                         locale: 'en',
                         data: data,
                         decimalPlaces: 4,
                         height: 600,
                         width: undefined,
                         yAxisUnit: {
                             text: 'DW05Unit01',
                             x: 100,
                             y: -20,
                             fontSize: '20pt'
                         }
             });
