ControlChart

Provide methods for drawing control chart .

Methods

static addPoint(seriesId, newPoint)

Add a new point to a specific series the series is specified by its seriesId. The control chart must be drawn before using ControlChart.chart method.

Parameters:
Name Type Description
seriesId string

The id of the series that being updated. For IDs of the series please refer ControlChart.seriesIds
newPoint number

The value of the point that being added.
Example
$('#chart').chart('addPoint', 'ucl_1', 19.90);
// This will add a new point at the right most side with the value of 19.90 in upper control limit of first series.

static createBase64Image(options)

  • Export the chart as base 64 image. Only support the compatible HTML5 browsers. For IE, it requires canvg.js from v3.0.8 to onwards.
Parameters:
Name Type Attributes Description
options object

An object with specified properties
containerId string

The id of an html input element e.g. base64Image when a tag is defined like this

width number <optional>

The width of chart. By default will take the chart container width where chart is rendered.
height number <optional>

The height of chart. By default will take the chart container height where chart is rendered.
success function

Callback when chart is rendered.
error function <optional>

Callback to get error information.
  • module:exporting.js
  • module:offline-exporting.js
  • module:canvg.js
Example
$('#chart').chart('createBase64Image', 
                                      {
                                          containerId : 'sImageBase64', 
                                          width : 1800, 
                                          height: 600, 
                                          success: function(){
                                                              console.log(document.getElementById('sImageBase64').value);
                                          },
                                          error: function(e) {
                                                              console.log(e);
                                          }
                                      });

static updatePoint(seriesId, sgNum, newValue)

this function update the value of a proper point, the point can be identified by its seriesID and sortNumber. The control chart must be drawn before using ControlChart.chart method.

Parameters:
Name Type Description
seriesId string

The id of the series that being updated. For IDs of the series please refer ControlChart.seriesIds
sgNum number

The subgroup Number of the point that being updated.
newValue number

the new Value of the Point that being updated.
Example
$('#chart').chart('updatePoint', 'ucl_1', 2,  19.90);
// This will update the value of third subgroup with the new given value 19.90. Please remember that subgroup number always start from 0.

object

customInfo

An array of objects with following properties can be injected against each subgroup.

Properties:
Name Type Description
label string

The label to be display in tooltip.
value string

The value to be used to show in tooltip and for xAxis labels.
showInTooltip boolean

if true, the label and value will also be showin in tooltip for a particular subgrup as 'label: value'
xAxisLabel boolean

If true then value of will be showin on xAxis labels instead of default labels. e.g. subgroup number
isRemark boolean

If true then the info on the Custome Info object will be treated as a Remark which will be shown in a Flag series over the series
Example

A customInfo can be injected like this, if a data is defined in the given format, please refer ControlChart.data

    data.subgroups[0].customInfo = [
        {
            label: 'Charge Number',
            value: 'CH001',
            showInTooltip: true,
            xAxisLabel: false
        },
        {
            label: 'Date',
            value: '05-01-2020',
            showInTooltip: true,
            xAxisLabel: true
        }
    ];
  // Note: If against a subgroup more than one objects have 'xAxisLabel' true then the value by default
  // of the first object will be taken. e.g. If in the given example both objects have xAxisLabel true
  // then in chart the value of first object on xAxis label (for subgroup 0) will be displayed.
  // Which is in this case 'CH001'
